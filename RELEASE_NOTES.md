# PNORDE v0.5.2-alpha.1 — first public alpha

Independent polymetric sequencing, MIDI CC macros and dedicated modulation lanes, multiple themes, clock-reactive lighting, presets, randomisation and global automation.

**Platform:** Windows x64, VST3.  
**Reported host test:** Ableton Live 12 on Windows 11.  
**Status:** Public alpha / pre-release. Please report bugs and expect breaking changes.

**Created by:** LANTERNS (Nova O'Reilly), Altered Wave Studios.  
**Influenced by:** Arturia Pigments and VCV Rack (independent, unaffiliated project).

**Install:** Unzip `PNORDE-v0.5.2-alpha.1-Windows-x64-VST3.zip`, and copy its `.vst3` bundle folder into the Windows system VST3 directory. The legacy Polyrhythm MIDI plugin need not be removed.
